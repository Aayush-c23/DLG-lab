# MNIST Digit Classification using CNN

## Aim

To build and train a Convolutional Neural Network (CNN) using TensorFlow/Keras to classify handwritten digits.

## Dataset Used

The **MNIST handwritten digit dataset** was used. It contains grayscale images of handwritten digits from 0 to 9, with images resized to **28 × 28 pixels**.

## Results

The CNN was trained for **5 epochs** using the Adam optimizer. The model achieved a **test accuracy of approximately 99.07%**, showing excellent performance in recognizing handwritten digits.
